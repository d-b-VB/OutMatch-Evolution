# Changelog

All notable changes to OutMatch Reach Evolution Lab are documented here. The
project follows semantic versioning for release tags and stored-format changes
retain their own explicit schema or rules versions.

## 0.1.0 — 2026-08-30

### Added

- Canonical deterministic Reach engine and complete R29 report reproduction.
- Worker-based three-stage evolution with migration, breeding, mutation, and wildcards.
- Durable IndexedDB checkpoints, pause/reload/resume, and atomic generation commits.
- Portable, integrity-checked `.omgen` export, import, and deterministic continuation.
- Production Lab run controls, population browser, reports, and lineage inspection.
- Audited move, copy, and versioned 112-locus replacement interventions.
- Explicit-color exhibitions, separate replay storage, and graphical replay timeline.
- Keyboard navigation, focus-return dialogs, skip navigation, and responsive layouts.
- Chromium acceptance, deterministic screenshots, consolidated verification, and
  project-subpath-safe GitHub Pages delivery.

### Compatibility

- Node.js 22 or newer is required for development and release verification.
- Intervention schema v1 remains readable; replacement uploads require v2.
